**RULEs**

1. Ask questions when planning or making any changes, don't implement if you are unsure or not clarified.
2. Don't run `npx expo start -c` only the developer will run it, and do the manually tested.
3. Always read the `session-context.md` once per session, so that way you have full context of the current changes.
4. If you have suggestion or recommendations, always provide 3 or more options.
5. Don't always update the `session-context.md` only once the user ask you to update it.
6. Never make any decisions on your own, always ask the user for clarification or approval.
7. Don't push a commit.
8. Always create an implementation plan before implementing a new feature or fixing something.
9. If implementing related to front end or UI, always make sure to follow carefully the `DESIGN.md`.
